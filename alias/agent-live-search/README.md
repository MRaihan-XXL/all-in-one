# agent-live-search

**Alias of [`aio-connect`](https://www.npmjs.com/package/aio-connect)** — the
same CLI under a secondary name, so it is easier to find by what it does.

```bash
npx agent-live-search ask "csv to interactive chart"
npx agent-live-search doctor
```

Identical commands, flags and output — the wrapper just delegates to
`aio-connect/bin/aio.js`. Docs, issues and releases live in the main package:
<https://github.com/MRaihan-XXL/all-in-one>
